# Borrowed Time

**Freeze time. Stitch through enemies. Steal their bullets.**

A 3D cyberpunk arena survival game made for Haven. Fight through three increasingly difficult stages, collect XP, upgrade your build, and defeat the Collector.

## Play

[Play Borrowed Time on itch.io](https://aryanp3356gmailcom.itch.io/borrowed-time)

## The Twist

Hold Space to freeze enemies and bullets while you keep moving. Place pins to connect glowing threads across the battlefield, then release Space to cut enemies and turn crossed hostile bullets into friendly shots.

Freezing builds time debt. After release, enemies accelerate until that debt clears—so plan your escape!

## Characters

- **Runner:** Fast, accurate pulse rifle.
- **Wraith:** Powerful arrows that pierce multiple enemies.
- **Breaker:** Short-range scattergun for fighting crowds.

All three share the same freeze, thread, and dash controls.

## Controls

| Key | Action |
| --- | --- |
| WASD / Arrow keys | Move |
| Mouse | Aim |
| Hold left click | Fire |
| Hold Space | Freeze time |
| Left click while frozen | Place pins |
| Release Space | Snap threads and steal crossed bullets |
| Shift | Dash |
| 1 / 2 / 3 | Choose an upgrade |
| F | Toggle auto-fire |
| Esc | Pause / Help |
| M | Toggle sound |
| V | Toggle reduced effects |
| Enter | Start / Confirm / Restart |
